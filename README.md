## 🤔 这是什么？

一个**基于 RAG（检索增强生成）的多轮对话机器人**。

简单说：你上传一个文档（比如课本、论文、笔记），然后像跟朋友聊天一样向它提问。它会从文档里找到最相关的内容，结合上下文，用自然语言回答你。

---

## ✨ 核心功能（一图看懂）

| 功能 | 说明 | 为什么有用 |
|------|------|-----------|
| 📄 **多格式文档** | 上传 .txt 或 .pdf，自动提取文本 | 教材、论文、会议记录都能用 |
| ✂️ **语义切块** | 按句号/问号/感叹号切分，超长句再按逗号切 | 保证每个检索单元语义完整，不会断在奇怪的地方 |
| 🔍 **双阶段检索** | 向量召回 top-10 → 交叉编码器重排取 top-3 | 精准命中相关内容，不被无关段落干扰 |
| 💚 **情绪感知** | 检测输入中的负面词（烦、累、焦虑、emo…） | 自动加一句温暖回应，像真人在倾听 |
| 🎭 **角色切换** | 心理辅导员 / 学习搭子 / 树洞三种人设 | 不同场景一键换风格，回答语气完全不同 |
| 💾 **对话记忆** | 历史自动存到 history.json，重启不丢失 | 下次打开页面接着聊 |
| ⚡ **流式输出** | DeepSeek API 逐字返回 | 像打字机一样实时显示，不用干等 |
| 🎨 **现代界面** | Gradio 软主题 + 示例问题 + 按钮组 | 美观好用，点一下就问 |

## 🚀 5 分钟跑起来

### 1. 克隆仓库

`ash
git clone https://github.com/fei-fff/rag-chatbot.git
cd rag-chatbot
`

### 2. 安装依赖

`ash
pip install -r requirements.txt
`

### 3. 配置 API Key

打开 pp.py，修改第 9 行：

`python
API_KEY = "sk-your-deepseek-api-key"
`

> 去 [DeepSeek 开放平台](https://platform.deepseek.com) 注册就能免费领额度。

### 4. 启动

`ash
python app.py
`

浏览器打开 http://127.0.0.1:7860，上传一个文档开始聊天！

## 🎮 使用指南

### 基础流程

1. 点击 **上传文档**，选一个 .txt 或 .pdf 文件
2. 看到「文件已加载，共 XX 个文本块」说明就绪
3. 在输入框打字提问，按回车或点发送
4. 回答逐字流式显示，可以追问、深挖

### 角色切换

| 角色 | 适合场景 | 回答风格 |
|------|---------|---------|
| 📖 **学习搭子** | 日常学习、查资料 | 热情鼓励，像朋友一起学 |
| 🫂 **心理辅导员** | 感到疲惫、焦虑、迷茫 | 温暖共情，专业引导 |
| 🕳️ **树洞** | 只想倾诉，不需要建议 | 安静倾听，简短回应 |

### 情绪关键词自动触发

当你说「好累」「焦虑了」「压力好大」……时，机器人会自动先给一句共情的话，再回答问题。

目前支持的关键词：烦 / 累 / 焦虑 / emo / 压力 / 难过 / 伤心 / 崩溃 / 绝望 / 迷茫 / 沮丧 / 紧张 / 害怕 / 孤独 / 无聊 / 生气 / 暴躁 / 疲惫 / 抑郁 / 不安 / 失眠 / 烦躁 / 痛苦 / 无助 / 委屈

## 🔧 技术架构

`
用户提问
   │
   ▼
┌──────────────┐    ┌─────────────────────────────────┐
│  情绪检测     │───▶│ 匹配到负面词 → 添加共情前缀        │
│  (关键词匹配) │    │ 未匹配 → 跳过                    │
└──────────────┘    └─────────────────────────────────┘
   │
   ▼
┌──────────────┐    ┌─────────────────────────────────┐
│  文档预处理   │    │ PDF → pdfplumber 逐页提取          │
│  (上传时)    │───▶│ TXT → 直接读取                    │
└──────────────┘    │ 按句子切块 → SentenceTransformer   │
                    │ 向量化 → 存入内存                  │
                    └─────────────────────────────────┘
   │
   ▼
┌──────────────┐    ┌─────────────────────────────────┐
│  第一阶段检索 │    │ 问题向量与文档块向量做点积          │
│  (向量召回)  │───▶│ 取相似度最高的 top-10              │
└──────────────┘    └─────────────────────────────────┘
   │
   ▼
┌──────────────┐    ┌─────────────────────────────────┐
│  第二阶段排序 │    │ CrossEncoder 对 10 个候选重打分     │
│  (Rerank)   │───▶│ 取最相关的 top-3                 │
└──────────────┘    └─────────────────────────────────┘
   │
   ▼
┌──────────────┐    ┌─────────────────────────────────┐
│  生成回答     │    │ System Prompt = 角色人设 + 资料    │
│  (DeepSeek) │───▶│ + 共情前缀                        │
└──────────────┘    │ Messages = 历史对话 + 当前问题     │
                    │ Stream = True → 逐字返回          │
                    └─────────────────────────────────┘
`

## ⚙️ 模型说明

首次运行会自动从 HuggingFace 下载（已设国内镜像 hf-mirror.com）：

| 模型 | 用途 | 大小 |
|------|------|------|
| ll-MiniLM-L6-v2 | 向量嵌入（文档/问题转向量） | ~80MB |
| cross-encoder/ms-marco-MiniLM-L-6-v2 | 交叉编码器（重排序） | ~80MB |
