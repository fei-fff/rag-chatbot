## 🤔 这是什么？

一个**基于 RAG（检索增强生成）的全能文件问答机器人**。

简单说：你随便上传一个文件——课本、论文、照片、会议录像、代码仓库——然后直接向它提问。它会自动读懂文件内容，找到最相关的信息，用自然语言回答你。

**和普通聊天机器人的区别**：不是靠模型记忆，而是实时从你的文件里检索证据再回答，杜绝幻觉。

## ✨ 你能上传什么？（全都支持）

| 类型 | 格式 | 处理方式 |
|------|------|----------|
| 📄 **文档** | PDF | pdfplumber 逐页提取文字 |
| 📝 **Word** | DOCX | python-docx 解析段落 |
| 📃 **文本** | TXT / MD / CSV / JSON / XML / YAML | 直接读取（自动处理 UTF-8 / GBK 编码） |
| 💻 **代码** | PY / JS / TS / HTML / CSS / C / CPP / Java / Go / Rust / SQL / SH / PS1 ... | 当作文本索引，可问答代码逻辑 |
| 🖼️ **图片** | JPG / PNG / GIF / WebP / BMP | DeepSeek 多模态 API 自动描述内容（物体、文字、场景） |
| 🎬 **视频** | MP4 / AVI / MOV / MKV / WebM | OpenCV 提取关键帧 → 逐帧多模态描述 |

## ✨ 核心功能全览

| # | 功能 | 一句话说明 | 为什么重要 |
|---|------|-----------|-----------|
| 1 | 🌐 **万能文件上传** | PDF/Word/图片/视频/代码/表格全支持 | 一个工具处理所有资料，不用来回切换 |
| 2 | 🤖 **AI 视觉识别** | 图片→文字描述，视频→关键帧描述 | 照片、截图、录像都能被检索问答 |
| 3 | ✂️ **语义切块** | 按句子切分，超长句按逗号再切 | 检索单元语义完整，不会断在半句话 |
| 4 | 🔍 **双阶段检索** | 向量召回 top-10 → 交叉编码器重排 top-3 | 精准定位，不被无关内容干扰 |
| 5 | 💚 **情绪感知** | 检测 25 个负面情绪词，自动共情 | 你累了烦了，机器人先安慰再回答 |
| 6 | 🎭 **三角色切换** | 学习搭子 / 心理辅导员 / 树洞 | 不同场景一键换人设，语气完全不同 |
| 7 | ⚡ **流式输出** | 像打字机逐字显示 | 不用干等，实时看到生成过程 |
| 8 | 💾 **对话记忆** | 历史存到 JSON，重启不丢 | 关掉页面下次打开接着聊 |
| 9 | 🎨 **现代界面** | Gradio Soft 主题 + 示例按钮 + 复制 | 好看好用，零学习成本 |
| 10 | 🔄 **多轮对话** | 上下文记忆，可追问深挖 | 像真人聊天一样自然连贯 |

## 🚀 5 分钟跑起来

### 1. 克隆仓库

`ash
git clone https://github.com/fei-fff/rag-chatbot.git
cd rag-chatbot
`

### 2. 安装依赖

`ash
pip install -r requirements.txt
`

> 如果要用视频识别功能，额外安装：
> `ash
> pip install opencv-python
> `

### 3. 配置 API Key

打开 pp.py，修改第 9 行：

`python
API_KEY = "sk-your-deepseek-api-key"
`

> 去 [DeepSeek 开放平台](https://platform.deepseek.com) 注册即送免费额度。图片/视频识别用的是同一个 API，按 token 计费。

### 4. 启动

`ash
python app.py
`

浏览器打开 http://127.0.0.1:7860，上传文件开始聊天！

## 🎮 使用指南

### 基础三步走

1. **上传文件** — 拖拽或点击上传任意格式文件
2. **等待处理** — 看到「已加载，共 XX 个文本块」说明就绪（图片/视频需要调用 API，稍等几秒）
3. **打字提问** — 输入问题按回车，回答逐字流式显示

       ▼                        ▼

         │             ┌──────────────────┐
         ▼             │ 交叉编码器重排     │
┌──────────────────┐   │ CrossEncoder     │
│ 按句子语义切块    │   │ 10选3 最相关     │
│ 生成文档块列表    │   └────────┬─────────┘
└────────┬─────────┘            │
         ▼                      ▼
┌──────────────────────────────────────────┐
│              DeepSeek API 生成回答         │
│  System Prompt = 角色人设 + 共情 + 资料   │
│  Messages = 历史对话 + 当前问题           │
│  Stream = True → 逐字流式返回             │
└──────────────────────────────────────────┘

## ❓ FAQ

**Q: 图片识别需要额外付费吗？**
A: 不需要，用的是 DeepSeek 多模态 API，和文本对话共用同一套计费。

**Q: 视频处理很慢吗？**
A: 每 5 秒提取一帧，最多 10 帧，一个 5 分钟视频约 1 分钟处理完。

**Q: 能上传多大的文件？**
A: 文本文件无限制。图片超过 20MB 会自动压缩。视频建议 200MB 以内。

**Q: 上传的代码文件能问什么？**
A: 可以问「这个函数做了什么」「有哪些 bug」「怎么优化」，AI 会从代码内容里检索回答。
